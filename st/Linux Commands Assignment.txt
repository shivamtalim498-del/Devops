1. Creating and Renaming Files/Directories
Objective
Create a directory named test_dir.
Create an empty file named example.txt inside it.
Rename the file to renamed_example.txt.
Commands
mkdir test_dir
touch test_dir/example.txt
mv test_dir/example.txt test_dir/renamed_example.txt
Explanation
mkdir test_dir creates a new directory named test_dir.
touch test_dir/example.txt creates an empty file named example.txt inside the directory.
mv renames the file from example.txt to renamed_example.txt.

Objective

Commands

4. Zipping and Unzipping
Objective
Compress the test_dir directory into test_dir.zip.
Extract it into a new directory named unzipped_dir.
Commands
zip -r test_dir.zip test_dir
mkdir unzipped_dir
unzip test_dir.zip -d unzipped_dir
Explanation
zip -r compresses the directory recursively.
mkdir creates a new destination folder.
unzip -d extracts the ZIP archive into the specified directory.

6. Changing Permissions
Objective

Create a file named secure.txt and make it read-only for everyone.

Commands
touch secure.txt
chmod 444 secure.txt
ls -l secure.txt
Explanation
touch creates the file.
chmod 444 gives read-only permission to the owner, group, and others.
ls -l displays the updated permissions.
